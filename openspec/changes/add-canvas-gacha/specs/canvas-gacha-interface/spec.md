## ADDED Requirements

### Requirement: 抽卡页面以 HTML Canvas 2D 呈现
系统 SHALL 在浏览器中以 HTML Canvas 2D 绘制主要抽卡画面、卡面及动画，并提供可操作的单抽与十连入口。

#### Scenario: 页面初次打开
- **WHEN** 用户打开抽卡页面且视觉素材加载完成
- **THEN** 系统显示星穹幻想主题画面、抽卡入口和可辨识的 3★、4★、5★ 视觉层级

#### Scenario: 触发单抽
- **WHEN** 用户激活单抽入口
- **THEN** 系统启动一次单抽流程，并最终显示一张本次抽到的卡牌

### Requirement: 原创角色卡面可辨识
系统 SHALL 使用原创角色插画呈现抽卡结果，并以文字与视觉效果同时标示角色名称和稀有度。

#### Scenario: 展示不同稀有度卡面
- **WHEN** 抽卡结果包含任意稀有度的角色
- **THEN** 对应卡面显示该角色的插画、名称和星级，且 5★ 的视觉反馈明显强于较低稀有度

### Requirement: 页面适配桌面与手机
系统 SHALL 随视口尺寸与设备像素比调整 Canvas 显示尺寸、绘制清晰度和交互命中区域。

#### Scenario: 手机视口操作
- **WHEN** 用户在常见竖屏手机视口打开页面
- **THEN** 抽卡入口与结果内容保持可见，用户可用触控完成抽卡及结果查看

#### Scenario: 桌面视口操作
- **WHEN** 用户在桌面视口打开页面
- **THEN** 抽卡入口与结果内容保持可见，用户可用鼠标完成抽卡及结果查看
