# Triage Labels

| Canonical role | 本项目状态 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给代理执行 |
| `ready-for-human` | `ready-for-human` | 需要人工处理 |
| 终态 | `closed` | 已交付并关票 |
| `wontfix` | `wontfix` | 不计划处理 |

票据的 `Status:` 使用右列字符串。更改本项目状态名时，同步更新本表与现有票据。
