## 端到端目标

在同一页面加入十连入口：一次生成恰好十张结果，当前十连内兑现 4★ 保底，并绘制可查看的十张结果总览。

## 验收标准

- [ ] 每次十连恰好十张卡牌，且至少一张为 4★ 或以上。
- [ ] 十次基础抽取均为 3★ 时，仅将其中一张提升为 4★ 并重新选取对应角色。
- [ ] 基础抽取已含 4★/5★ 时保留原结果，不额外替换。
- [ ] 连续多次十连各自独立满足保底，不累计跨十连计数。
- [ ] 不限制重复角色（同一角色可在一次十连中出现多次）。
- [ ] 总览一次呈现十张卡面，卡面名称与星级可读。

## 测试点（Vitest）

- 全 3★ 注入序列 → 结果含 1 张 4★、共 10 张。
- 已有 4★ / 已有 5★ 注入序列 → 与基础十次结果逐张相同。
- 连续三次十连 → 每次都 ≥1 张 4★+，且第二次不受第一次影响。
- 张数恒为 10。

## 人工浏览器验收

桌面点击十连，核对总览为十张且至少一张高稀有度。
