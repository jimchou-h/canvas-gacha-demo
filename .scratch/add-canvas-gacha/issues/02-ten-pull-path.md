## 端到端目标

在同一页面加入十连入口：一次生成恰好十张结果，当前十连内兑现 4★ 保底，并绘制可查看的十张结果总览。

## 验收标准

- [x] 每次十连恰好十张卡牌，且至少一张为 4★ 或以上。
- [x] 十次基础抽取均为 3★ 时，仅将其中一张提升为 4★ 并重新选取对应角色。
- [x] 基础抽取已含 4★/5★ 时保留原结果，不额外替换。
- [x] 连续多次十连各自独立满足保底，不累计跨十连计数。
- [x] 不限制重复角色（同一角色可在一次十连中出现多次）。
- [x] 总览一次呈现十张卡面，卡面名称与星级可读。

## 测试点（Vitest）

- `test/ten-pull.test.ts`：全 3★ 注入序列 → 第 10 张为 4★ 且改取 4★ 角色；已有 4★ / 已有 5★ → 与基础十次结果逐张相同；连续三次十连独立；60 轮 LCG 随机流下张数恒为 10 且至少一张 4★+；重复角色允许。
- `test/summary-grid.test.ts`：320×600、390×720、1440×900 三种视口下十张卡面全在画面内且两两不重叠；小屏卡面宽度 ≥60px；保持 1:1.4 竖版比例。

## 人工浏览器验收（并入阶段 4 清单）

桌面点击十连，核对总览为十张且至少一张高稀有度；手机竖屏下总览不溢出、名称可读。
